# Kolejli — Yakında Sizlerle

Minimal, duyarlı yakında sayfası. Ürün fotoğrafınızı `images/ayakkabi.jpg` adıyla ekleyin; arka plan otomatik görünür ve sekme simgesi fotoğraf olur. Fotoğraf yoksa koyu arka plan devam eder.

## Google Sites'e ekleme
Google Sites statik HTML/CSS/JS dosyalarını doğrudan site olarak yükleyip yayınlamaz. Bu sayfayı GitHub Pages, Netlify veya benzeri bir statik hosting hizmetinde yayınlayın; ardından Google Sites'te **Ekle > Yerleştir > URL** ile yayın adresini ekleyin. Tam ekran görünüm için yerleştirme çerçevesini sayfa boyunca büyütün. Alan adınızı barındırma hizmetine bağlayıp yönlendirebilirsiniz.
